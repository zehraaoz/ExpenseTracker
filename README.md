# Expense Tracker

A simple desktop application for managing personal expenses.

## Features

- Add expenses
- Delete expenses
- Categorize expenses
- Select expense dates
- View expenses in a table
- Calculate the total amount of expenses

## Technologies

- Java
- JavaFX
- Maven
- IntelliJ IDEA

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Maven dependencies are loaded.
4. Run the `Main` class.
